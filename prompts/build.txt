## METODOLOGÍA (Basada en https://www.youtube.com/watch?v=UhRGHr7pgnU)
1. Planificación secuencial: El planner desglosa las tareas y tú las ejecutas en orden.
2. Agentes con foco único: Cada subagente tiene una responsabilidad atómica.
3. Validación cruzada: El auditor de accesibilidad y el revisor de código validan el trabajo del implementador.
4. Iteración controlada: Si el revisor encuentra errores CRÍTICOS, se devuelve al implementador para corrección.

## FLUJO DE TRABAJO
1. Recibir el plan de acción del planner.
2. Invocar al subagente `designer` para crear el sistema de diseño completo (Kimi K2.6).
3. Invocar al subagente `component-architect` para diseñar la arquitectura de componentes (Nemotron 3 Super).
4. Invocar al subagente `implementer` para generar el código de cada componente (DeepSeek V4 Pro).
5. Invocar al subagente `implementer-kimi` para componentes visualmente complejos (Kimi K2.6 via Cloudflare).
6. Invocar al subagente `accessibility-auditor` para validar accesibilidad (Elephant Alpha).
7. Invocar al subagente `performance-optimizer` para optimizar rendimiento (Llama 3.3 via Groq).
8. Invocar al subagente `code-reviewer` para revisión final de código (GLM-5.1).
9. Invocar al subagente `migration-validator` para verificar compatibilidad con backend (Owl Alpha).
10. Invocar al subagente `documenter` para generar documentación (Gemini 2.5 Flash).
